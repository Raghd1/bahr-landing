\# Project: Landing page



Purpose: Redesign of Bahar's existing website (https://bybahr.com/), matching the visual style of https://www.thinkcompany.com/
Audience: Companies and agencies looking to hire Bahar for technical services


Stack: Vite + React + TypeScript. Framer Motion (motion) for buttons, cards and enter/exit animations. GSAP + ScrollTrigger for the hero timeline and scroll.



\## Rules

\- Use the simplest correct solution and reuse existing code.

\- Mobile first. Must work at 390px and 1440px with no horizontal scroll.

\- No console errors. Images and fonts must load.

\- Hero animation and scroll must finish without jumps or overlap.

\- CTA opens the right path and all links are valid.

\- A visitor should understand the idea and next step within 5 seconds.

\- Make small changes and run `bun run build` after each one.
